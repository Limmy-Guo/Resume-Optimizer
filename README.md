# 🚀 AI Resume Optimizer

> **An LLM-powered application that helps job seekers tailor their resumes to specific job descriptions instantly.**

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen)](https://resume-optimizer-blond-one.vercel.app/) 
[![Built With Claude](https://img.shields.io/badge/AI-Anthropic_Claude-blue)](https://www.anthropic.com/)

## 📖 Overview

As an MBA candidate and former strategist, I realized that the most time-consuming part of recruiting is bridging the gap between a candidate's experience and a specific Job Description (JD). 

I built this **MVP (Minimum Viable Product)** to solve that pain point. By leveraging the **Anthropic Claude API**, this tool acts as an intelligent career coach, analyzing resumes against JDs to provide actionable, keyword-optimized tailoring suggestions in seconds.

## ✨ Key Features

* **Smart Matching:** Uses Large Language Models (LLMs) to semantically compare resume content with JD requirements.
* **Gap Analysis:** Identifies missing keywords and skills required by the ATS (Applicant Tracking System).
* **Actionable Feedback:** Generates specific, rewritten bullet points that highlight relevant experience without fabricating facts.
* **Instant Optimization:** Reduces the time spent on resume tailoring from hours to minutes.

## 🛠️ Tech Stack

* **Frontend:** HTML/CSS/JavaScript (Clean & Responsive UI)
* **AI Engine:** Anthropic Claude API (Claude 3.5 Sonnet)
* **Deployment:** Vercel (Serverless Functions)
* **Version Control:** Git & GitHub

## 🚀 How It Works

1.  **Input:** User pastes their existing Resume and the target Job Description.
2.  **Processing:** The app sends a structured prompt to the Claude API, instructing it to act as an expert recruiter.
3.  **Output:** The LLM returns an optimized resume with highlighted keywords
